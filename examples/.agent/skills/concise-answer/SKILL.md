# Concise answer

When this skill is active, shape the final answer as follows.

## Structure

1. One-sentence direct answer first.
2. Up to five supporting bullets, each a single line.
3. No filler, hedging, or restating the question.

## Checklist

- Lead with the conclusion.
- Prefer numbers and concrete nouns over adjectives.
- Stop when the question is answered.
